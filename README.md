# ប្រព័ន្ធស្រង់អវត្តមានថ្វាយបង្គំ - វត្តខេមរវ័ន (បឹងស្នួល)

ប្រព័ន្ធគ្រប់គ្រងអវត្តមានថ្វាយបង្គំ បែបពុទ្ធសាសនា សម្រាប់វត្តអារាម និងសាលាពុទ្ធិកសិក្សា (Buddhist Worship Attendance Web Application)។

## 🌟 លក្ខណៈពិសេស (Features)
- 🎨 **UX/UI បុរាណបែបពុទ្ធសាសនា**៖ តុបតែងដោយដើមពោធិព្រឹក្ស (Bodhi Tree), ស្លឹកពោធិ៍មាសជ្រុះ, និង Logo វត្តខេមរវ័ន (បឹងស្នួល)។ Responsive ល្អឥតខ្ចោះ ទាំងលើ PC និង Phone។
- 📝 **ផ្ទាំងទី២៖ ស្រង់អវត្តមានប្រចាំថ្ងៃ**៖ ស្វែងយល់ដោយស្វ័យប្រវត្តិតាម System Clock (Smart Time Detection) ថាម៉ោងបច្ចុប្បន្នជា **"☀️ វេនព្រឹក"** ឬ **"🌙 វេនល្ងាច"**។
- 📊 **ផ្ទាំងទី១៖ តារាងអវត្តមាន ១ខែ**៖ បង្ហាញទិន្នន័យអវត្តមានសរុបពេញ ១ខែ (ថ្ងៃទី១-៣១) រាប់សរុប (វត្តមាន, ច្បាប់, អវត្តមាន, យឺត) មានប៊ូតុង **Export ជា Excel (CSV)** និងបោះពុម្ព (Print)។
- 📈 **ផ្ទាំងទី៣៖ ស្ថិតិ (១ថ្ងៃ / ១អាទិត្យ / ១ខែ)**៖ បង្ហាញស្ថិតិអវត្តមានតាមសមណសិស្ស/សិស្សម្នាក់ៗ តាមចន្លោះពេល ១ ថ្ងៃ, ១ អាទិត្យ, និង ១ ខែ។

- ថ្នាក់រៀនចំនួន ១៥ ថ្នាក់ (ថ្នាក់ទី១ ដល់ ថ្នាក់ទី១៥)
- សមណសិស្ស/សិស្សចំនួន ៧ អង្គ/នាក់ ក្នុងមួយថ្នាក់ (សរុប ១០៥ អង្គ/នាក់)
